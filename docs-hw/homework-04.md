## Задача 1. Метод `delete(uuid)`

Добавить `delete(self, uuid: UUID) -> None` в интерфейс `UsersRepository` и в обе реализации.

Критерии приёмки:

- в интерфейсе метод помечен `@abstractmethod`;
- `InMemoryUsersRepository.delete` удаляет пользователя из словаря; `SqliteUsersRepository.delete` выполняет `DELETE … WHERE uuid = :uuid` с параметром и вызывает `commit()`;
- для несуществующего `uuid` обе реализации бросают `UserNotFoundException` (в SQLite подсказка: у курсора есть `rowcount`);
- после удаления `get(uuid)` бросает `UserNotFoundException`; это проверено вручную скриптом `check_delete.py` для обеих реализаций.

## Задача 2. Скрипт, где замена реализации — одна строка

Написать `swap_demo.py`, который выбирает репозиторий в одной строке (`users_repository = …`), сохраняет двух пользователей и печатает их через `get_by_username`.

Критерии приёмки:

- весь остальной код скрипта не зависит от реализации, импорты `sqlite3` нужны только в строке/блоке создания Sqlite-варианта;
- скрипт запускается обеими вариантами: `python swap_demo.py` с `InMemory` и с `Sqlite`; вывод одинаковый по форме;
- в комментарии в одном-двух предложениях объясните, что именно гарантирует интерфейс.

## Задача 3. Метод `get_all() -> list[User]`

Добавить в интерфейс и обе реализации.

Критерии приёмки:

- `InMemory` возвращает новый список (`list(self._users.values())`), а не внутренний объект словаря: изменение возвращённого списка не влияет на репозиторий;
- `Sqlite` использует `fetchall()` и собирает `User` тем же способом, что `_fetch_user` (дублировать разбор строки нельзя: вынести общую функцию/метод);
- пустой репозиторий даёт `[]`, а не исключение;
- проверено скриптом для обеих реализаций.

Дополнительно (по желанию): воспроизведите в своём коде типичные ошибки и приложите текст каждой: забытый `commit()`; повторный `username` (`sqlite3.IntegrityError: UNIQUE constraint failed`); запуск `python blog/uuid.py` вместо запуска из корня; запрос к базе, где ещё нет таблицы (`sqlite3.OperationalError: no such table`); создание экземпляра интерфейса `UsersRepository`.
