## Задача 1. Абстрактный класс `PaymentMethod`

Абстрактный класс `PaymentMethod` с абстрактным методом `pay(amount)` и обычным методом `describe()`, который печатает название способа оплаты. Две реализации, например `CardPayment` и `CashPayment`.

Критерий приёмки:

- `PaymentMethod` наследуется от `ABC`, `pay` помечен `@abstractmethod`;
- `PaymentMethod()` бросает `TypeError` (в примерах запуска ловится через `try/except` и выводится сообщение);
- обе реализации создаются и их `pay(100)` что-то возвращает или печатает, результаты различаются;
- наследник без `pay` не создаётся (проверка вручную: `TypeError`);
- у каждой реализации свой `__init__`, вызывающий `super().__init__()`, если у родителя он есть.

## Задача 2. Класс `Money`

Класс `Money` с суммой и валютой (по умолчанию `"RUB"`), методами `__str__`, `__eq__`, `__add__`.

Критерий приёмки:

- `str(Money(5))` даёт `5 RUB`, а `repr(Money(5))` вида `Money(amount=5, currency='RUB')` (метод `__repr__` обязателен);
- `Money(5) == Money(5)` — `True`, `Money(5) == Money(7)` — `False`, `Money(5, "USD") == Money(5)` — `False`;
- `Money(5) + Money(7)` — новый объект с суммой 12 и той же валютой; исходные объекты не изменились;
- сложение разных валют бросает `ValueError` (сообщение на английском);
- `Money(5) == 5` не падает с `AttributeError` (возвращает `False` через `NotImplemented`).

## Задача 3. Интернет-магазин из ДЗ урока 1 по пакету

Разложить классы магазина из основного задания урока 1 (`shop.py`) по пакету `shop/`: например, `shop/product.py` (товар и наследники), `shop/cart.py`, `shop/user.py`, `shop/review.py`, `shop/feedback.py` + `shop/__init__.py`. Единая точка запуска `shop_run.py` в корне импортирует классы из пакета и печатает примеры. Базовый класс товара сделать абстрактным (`ABC`), если у него есть метод, который каждый наследник обязан реализовать по-своему (например, стоимость доставки), а для корзины добавить `__len__` и `__str__`.

Критерий приёмки:

- есть папка-пакет с `__init__.py`, в ней модули по одной сущности, в каждом свои классы без кода запуска;
- запуск `python shop_run.py` в консоли контейнера (рабочая папка `/app`, корень проекта) выполняется без ошибок;
- хотя бы один импорт сделан с `import … as …` или `from … import … as …` (осмысленный псевдоним);
- нет циклических импортов (корзина импортирует товар, но не наоборот), `ModuleNotFoundError` не возникает при запуске `python shop_run.py`;
- `len(cart)` и `print(cart)` работают; попытка создать объект абстрактного базового товара даёт `TypeError`.

Общее требование: имена в `snake_case`, комментарии и докстринги на русском, сообщения исключений на английском.
