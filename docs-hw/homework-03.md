# Домашнее задание к уроку 3. Структура проекта, uv, dataclass, Docker

Сдаётся в ветке `hw-3` от `lesson-3`:

## Задача 1. `Comment`

Dataclass `Comment(author: Person, post: Post, text: str)` в файле `blog/comment.py`. В `main.py` создать комментарий к посту из урока и вывести его на экран (нужен `__str__`, например «Автор комментария: текст»).

Критерий приёмки:

- класс объявлен через `@dataclass`, поля аннотированы, методы имеют аннотации (`-> str`);
- файл лежит в пакете `blog/`, импорт абсолютный (`from blog.person.person import Person`);
- `python main.py` в консоли контейнера печатает и пост, и комментарий без ошибок;
- `Comment(author, post, "текст") == Comment(author, post, "текст")` даёт `True` (проверка в REPL);
- у `Comment` нет собственного `__init__`.

## Задача 2. Собрать и запустить образ

Выполнить `make up`, `make shell`, `python main.py` на своей машине и приложить вывод (скриншот или текст) в описание сдачи.

Критерий приёмки:

- в выводе `make up` видны шаги сборки `[stage-0 1/6] … [stage-0 6/6]` без `ERROR` (если образ уже собран, они помечены `CACHED`: сделайте `docker compose build --no-cache` и приложите этот вывод);
- в выводе запуска есть строка с постом и строка с комментарием из задачи 1;
- второй запуск `make up` после правки только `main.py` показывает `CACHED` на шагах `4/6` и `5/6` (приложить фрагмент).

## Задача 3. Линтер

Привести код к виду, при котором команды чисты. Команды выполняются в консоли контейнера (`make shell`), uv на свою машину ставить не нужно.

Критерий приёмки:

- `uvx ruff check .` выводит `All checks passed!`;
- `uvx ruff format --check .` не сообщает о файлах, которые надо переформатировать;
- `.venv/` не попадает в коммит (`git status` не показывает её), `uv.lock` и `pyproject.toml` закоммичены;
- в `pyproject.toml` не добавлены лишние зависимости.

Общее требование ко всем задачам: имена в `snake_case`, аннотации типов на всех сигнатурах, комментарии и докстринги на русском, сообщения исключений на английском.
